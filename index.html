          Didn't find yours?

          What is Previa?

          Previa turns every GitHub pull request into its own live preview: the exact commit, built from your Dockerfile, running at a private HTTPS link that's posted right on the pull request.

          What does my repository need?

          Two files at its root: a Dockerfile and a .previewrc.yaml. The config can be as short as {}; by default Previa expects your app on port 3000. You can also set a health check path, environment variables and a size.

          Which languages and frameworks work?

          Anything that runs in a Docker container and answers HTTP: Node.js, Python, Ruby, Go, Java, PHP, static sites and more. APIs work too.

          When does a preview get built?

          In Manual mode (the default), when you press Build latest commit. In Automatic mode, five minutes after your last push. Either way, Previa checks with GitHub right before building.

          How long does a preview live?

          Until its pull request is closed or merged, or 48 hours after it was last published. Building again brings it back at the same link.

          Is Previa free?

          Yes. Previa is free while it's in early access, so you can explore it on your own pull requests.

          Does signing in give Previa my code?

          No. Signing in only tells Previa who you are. It reads code only in the repositories, public or private, where you install its GitHub App, and only to build previews and post comments and checks.

          Is it safe to build pull requests from forks?

          Yes. Every build and preview is isolated, and pull requests from forks never receive your secrets or extra connections.

          Who can open a preview?

          Anyone who has its link. Each link has a random part, so previews can't be guessed, but they aren't behind a login. Use test data and sandbox credentials, never production ones.

          What happens to my code?

          It's used only to build and run your preview. When the pull request closes or the preview expires, the preview and its data are removed.

          What if a build fails?

          The comment and check on the pull request say what went wrong, the full build log is one click away, and you can retry whenever you're ready.
