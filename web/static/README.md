# Browser assets

`htmx.min.js` is HTMX 2.0.11, downloaded from:
https://cdn.jsdelivr.net/npm/htmx.org@2.0.11/dist/htmx.min.js

SHA-384 (base64):
`2OatzQy1H+Zd/IIrjr1TcuDGqLXeHhbooAyJY1KdQMKnr4LZ22k31GBLdYKHmVjg`

License: `htmx.LICENSE.txt` (upstream Zero-Clause BSD).
The application embeds these assets and serves the script at `/static/htmx.min.js`.

`css/app.css` is generated by official Tailwind CSS v4.1.18 using `make assets`.
Edit `web/styles/app.css` and `theme.css`, not the compiled stylesheet. CSS is
Git-ignored, embedded at Go build time, and served at `/static/css/app.css`.
`brand/` holds Previa's logo: `favicon.svg` (follows the tab's light or dark theme),
`favicon-32.png` (also served at `/favicon.ico`), `apple-touch-icon.png`, and
downloadable PNGs: `previa-mark.png` / `previa-mark-on-dark.png` (512 px mark) and
`previa-logo.png` / `previa-logo-on-dark.png` (mark and wordmark, transparent, for
light and dark backgrounds). They share the geometry of `components.BrandMark`;
the wordmark is set in Inter Bold. Download them from the repository or from
`/static/brand/<file>` on a running dashboard.
`js/ui.js` is the one first-party script: small initializers for navigation,
dialogs, live updates and build logs that enhance working server-rendered pages.
Add behaviour there only when a page actually needs it.
